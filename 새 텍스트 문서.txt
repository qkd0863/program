sys.stdin.readline은 입력을 빠르게 받기 위해 사용합니다.
heapq는 우선순위 큐입니다. 다익스트라에서 현재 비용이 가장 작은 헛간을 먼저 꺼내기 위해 씁니다.

input = sys.stdin.readline
INF = int(1e18)

INF는 아주 큰 값입니다.
처음에는 아직 어떤 헛간까지의 최소 비용도 모르기 때문에 큰 값으로 초기화합니다.

N, M = map(int, input().split())
graph = [[] for _ in range(N + 1)]

N은 헛간 개수, M은 길 개수입니다.
graph[i]에는 i번 헛간과 연결된 헛간 정보가 들어갑니다.

for _ in range(M):
    A, B, C = map(int, input().split())
    graph[A].append((B, C))
    graph[B].append((A, C))

길은 양방향이므로 둘 다 넣습니다.

예를 들어:

2 4 0

이면,

graph[2].append((4, 0))
graph[4].append((2, 0))

처럼 저장합니다.

dist = [INF] * (N + 1)
dist[1] = 0

dist[i]는 1번 헛간에서 i번 헛간까지 가는 최소 비용입니다.

시작점은 1번 헛간이므로:

dist[1] = 0

입니다.

heap = []
heapq.heappush(heap, (0, 1))

우선순위 큐에 시작점을 넣습니다.

(현재까지 비용, 현재 헛간 번호)

형태입니다.

while heap:
    cost, now = heapq.heappop(heap)

비용이 가장 작은 헛간을 꺼냅니다.

if cost > dist[now]:
    continue

이미 더 짧은 경로를 알고 있다면 무시합니다.

예를 들어 now까지 비용 10짜리 정보가 큐에 들어있었는데, 나중에 비용 5짜리 경로를 찾았다면 비용 10짜리는 필요 없습니다.

for nxt, cow in graph[now]:

현재 헛간 now와 연결된 헛간들을 확인합니다.

new_cost = cost + cow

현재 헛간까지 온 비용 cost에 다음 길의 비용 cow를 더합니다.

if new_cost < dist[nxt]:
    dist[nxt] = new_cost
    heapq.heappush(heap, (new_cost, nxt))

더 싼 비용으로 nxt에 갈 수 있다면 갱신합니다.
그리고 그 헛간을 다시 우선순위 큐에 넣습니다.

print(dist[N])

마지막으로 N번 헛간까지 가는 최소 비용을 출력합니다.

정리하면:

가장 비용이 적은 헛간부터 꺼낸다
→ 연결된 길들을 확인한다
→ 더 싸게 갈 수 있으면 dist를 갱신한다
→ N번 헛간까지 최소 비용을 출력한다
